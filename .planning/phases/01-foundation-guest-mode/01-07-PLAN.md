## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Citizen (guest) → Backend | Untrusted; guest submission data validated server-side; rate limit 10 req/min/IP (per 01-03) |
| Citizen Web → Backend (BFF) | Untrusted; same public endpoints as mobile guest; no session; tracking code = UUID v7 |
| Backend → PostgreSQL | Trusted; parameterized queries; JSONB schema validation at write |
| Citizen Web → RÚIAN (via backend) | Trusted proxy; backend enforces rate limits; no API key exposed to browser |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Spoofing | Fake citizen-web look-alike | mitigate | HSTS; canonical domain; gov.cz visual identity used only by authorized apps |
| T-07-02 | Tampering | XSS via form data rendering | mitigate | React auto-escaping; no dangerouslySetInnerHTML; zod schema validation; CSP header in index.html |
| T-07-03 | Repudiation | Citizen denies submitting via web | mitigate | Audit log on backend (IP, UA, timestamp, tracking code); confirmation PDF as evidence |
| T-07-04 | Information Disclosure | Tracking code enumeration leaks submissions | mitigate | UUID v7 unguessable codes; rate limit lookup 10/min/IP; no list endpoint for guests |
| T-07-05 | Denial of Service | Form submission / autocomplete flood | mitigate | Rate limits enforced at backend (10/min submissions, 30/min autocomplete); Vite build + static hosting CDN |
| T-07-06 | Elevation of Privilege | Guest accesses admin or citizen data of others | mitigate | Citizen web hits only public endpoints; admin paths never exposed in citizen-web router; CORS allows only citizen-web origin |
| T-07-SC | Tampering | npm dependencies in citizen-web | mitigate | slopcheck + blocking human checkpoint for [ASSUMED]/[SUS] packages |
</threat_model>
