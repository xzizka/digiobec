## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Guest → Backend (confirmation download) | Untrusted; tracking code is UUID v7 (unguessable); rate limit 20/min/IP |
| Backend → File System (font cache) | Trusted internal; fonts bundled in JAR |
| Admin Web → Backend | Authenticated clerk; same endpoints, different authorization |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Spoofing | Fake PDF confirmation | mitigate | PDF includes QR code linking to verification endpoint; digital signature (Phase 2) |
| T-05-02 | Tampering | PDF content injection via form data | mitigate | Form data escaped in FO template; no raw XML interpolation; whitelist allowed characters |
| T-05-03 | Repudiation | Citizen denies PDF authenticity | mitigate | QR verification URL shows live status from backend; audit log of PDF downloads |
| T-05-04 | Information Disclosure | Tracking code enumeration via PDF download | mitigate | UUID v7 tracking codes; rate limit; no sequential IDs |
| T-05-05 | Denial of Service | PDF generation resource exhaustion | mitigate | Async generation (CompletableFuture); timeout 10s; queue limit 100; cache generated PDFs 1h |
| T-05-06 | Elevation of Privilege | Access other's confirmation | mitigate | Tracking code required; no auth but unguessable; audit log all accesses |
| T-05-SC | Tampering | npm/pub dependencies in PDF/QR libs | mitigate | slopcheck + blocking human checkpoint for [ASSUMED]/[SUS] packages |
</threat_model>
