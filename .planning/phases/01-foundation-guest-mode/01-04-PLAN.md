<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mobile → Backend (BFF) | Untrusted; rate limit 30 req/min/IP for autocomplete |
| Backend → RÚIAN API | Trusted external; API key in header; timeout 5s; circuit breaker |
| Backend → Czech POINT API | Trusted external; API key; timeout 10s; cache 1 hour |
| Backend → PostgreSQL (RÚIAN cache) | Trusted internal; read-only replica for autocomplete |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Spoofing | Fake RÚIAN responses | mitigate | HTTPS only; certificate pinning for RÚIAN/Czech POINT APIs |
| T-04-02 | Tampering | MITM on geocoding coordinates | mitigate | TLS 1.3; validate API responses against schema |
| T-04-03 | Repudiation | Citizen claims wrong address suggested | mitigate | Log autocomplete queries + selected suggestion (audit trail) |
| T-04-04 | Information Disclosure | Address autocomplete leaks resident data | mitigate | RÚIAN is public registry; no PII beyond address; no tracking codes in autocomplete |
| T-04-05 | Denial of Service | RÚIAN API rate limit exceeded | mitigate | Local PostgreSQL cache of RÚIAN (nightly import); Caffeine cache 10min; circuit breaker |
| T-04-06 | Elevation of Privilege | Abuse Czech POINT locator for reconnaissance | mitigate | Rate limit 20 req/min/IP; radius max 10km; no bulk export |
| T-04-SC | Tampering | npm/pub dependencies in map/geocoding | mitigate | slopcheck + blocking human checkpoint for [ASSUMED]/[SUS] packages |
</threat_model>
