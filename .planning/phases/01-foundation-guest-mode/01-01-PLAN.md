<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mobile App → Backend (BFF) | Untrusted client (citizen device) calls internal API; all input validated at route entry |
| Admin Web → Backend | Internal network but separate trust zone; authenticated clerk session |
| Backend → PostgreSQL | Trusted internal; parameterized queries only (R2DBC) |
| Backend → Keycloak | Trusted internal; mTLS in production |
| CI/CD → Container Registry | Supply chain; signed images, SLSA provenance |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Spoofing | Mobile→Backend health endpoint | accept | Health endpoint public by design; no sensitive data exposed |
| T-01-02 | Tampering | docker-compose.yml supply chain | mitigate | Pin base image digests (postgres@sha256:..., keycloak@sha256:...); cosign verify in CI |
| T-01-03 | Repudiation | CI pipeline build integrity | mitigate | GitHub Actions attestations + SLSA Level 2 provenance |
| T-01-04 | Information Disclosure | /actuator/health exposes DB/Keycloak status | mitigate | In production: management.endpoint.health.show-details=when_authorized |
| T-01-05 | Denial of Service | Health endpoint flood | mitigate | Rate limit at ingress (nginx/Gateway): 100 req/min per IP |
| T-01-06 | Elevation of Privilege | Default Keycloak admin creds in docker-compose | mitigate | Change default admin/password via KEYCLOAK_ADMIN/KEYCLOAK_ADMIN_PASSWORD env; not committed |
| T-01-SC | Tampering | npm/pip/cargo/maven/gradle dependencies | mitigate | slopcheck + blocking human checkpoint for [ASSUMED]/[SUS] packages in .planning/research/PACKAGE-LEGITIMACY.md (to be created) |
</threat_model>
